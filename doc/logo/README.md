# Zorba logo

- `zorba-logo.svg`: wordmark for light backgrounds (letters #111111, figure #2A83D9).
- `zorba-logo-dark.svg`: wordmark for dark backgrounds (letters #F2F4F7, figure #3B93E6).
- `zorba-mark.svg`: the dancing figure alone (#2A83D9); used as the site favicon.

The figure is the original Zorba dancing figure. The wordmark is the lowercase
word "zorba"; the figure height is 0.70 em.

The letters are Comfortaa SemiBold (600) outlines converted to paths. Comfortaa
is by Johan Aakerlund and licensed under the SIL Open Font License 1.1.
